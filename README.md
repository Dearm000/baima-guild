# 白马公会宣传网页

这是一个可以发布到网上的静态网页。发布后，搜索引擎才有机会收录。

## 想让别人能搜索到，需要做这几步

1. 把这个文件夹上传到一个公开网址，比如 GitHub Pages、Netlify、Vercel 或自己的服务器。
2. 把真实网址提交给搜索引擎：
   - 百度搜索资源平台
   - Google Search Console
   - Bing Webmaster Tools
3. 等搜索引擎抓取。通常需要几天到几周。

## 需要改的地方

`index.html` 里的联系方式现在还是占位内容，可以改成 QQ 群、Discord、服务器 IP 或审核表链接。
